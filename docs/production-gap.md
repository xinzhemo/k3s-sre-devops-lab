# 生产环境差距分析

## 当前环境
- 3 节点 K3s（1 Master + 2 Worker，单 Master）
- 本地存储
- 无外部负载均衡
- 本地镜像仓库
- 无集中日志系统
- 无生产级告警通道

## 迁移到生产需补充
1. 控制面高可用（3 Master）
2. 持久化存储（CSI）
3. 外部负载均衡
4. 镜像仓库（Harbor）
5. 日志系统（ELK/Loki）
6. 告警通道（飞书/钉钉/邮件）
7. etcd 备份对接对象存储

## 迁移路线图
1. etcd 备份 → 对象存储
2. 接入生产告警通道
3. 部署持久化存储
4. 升级控制面高可用
5. 接入日志系统
